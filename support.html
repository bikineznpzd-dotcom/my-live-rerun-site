Before requesting help

Include safe diagnostic details

Application environment
Application version, Windows version, GPU model, and whether CPU x264 or NVENC was selected.
Affected channel
Channel number, STOPPED / STARTING / LIVE / RECOVERING / ERROR state, and approximate time of the issue.
Media details
Container, codec, resolution, and whether the issue occurs in preview, streaming, or both.
Relevant log excerpt
Review it first. Remove user names, local paths if sensitive, authorization codes, tokens, Stream Keys, and account identifiers.

Quick checks

Common issues

01

Preview is blank

Confirm the file still exists. Unsupported codecs may require the application to generate a local H.264 preview proxy.

02

Local RTMP is unavailable

Confirm the local server is listening and that the destination uses `127.0.0.1` or `localhost` with the correct port.

03

Login controls are not operational

The current project includes client-side integration points, but real authentication requires a configured Client Key, loopback redirect URI, and a production Auth Broker that is not included.

04

No LIVE permission

Login Kit is not LIVE access. Check account eligibility and obtain any RTMP credentials only through an authorized platform channel.

05

CAPTCHA appears

Complete verification manually in the official platform interface. The application does not automate or bypass CAPTCHA.

06

Never send credentials

Do not include passwords, Client Secrets, authorization codes, access tokens, refresh tokens, session handles, or Stream Keys.
